# AI Agent Setup: dal prompt al progetto gestibile

Questo repository contiene i materiali degli studenti del corso.

In 10 lezioni da 4 ore impari a lavorare con un agente AI dentro VS Code: gli dai un compito preciso, controlli il risultato e salvi il lavoro con Git. Alla fine pubblichi un tuo progetto funzionante, con un link online.

Il corso è pensato per chi ha le basi di Python e C++ ma poca esperienza pratica. Poca teoria, molta pratica, nessun voto.

## Il metodo

1. Scrivi un compito chiaro.
2. Invialo all'agente.
3. Controlla le modifiche (diff).
4. Accetta, oppure annulla e chiedi di nuovo con più dettagli.
5. Fai commit e sincronizza.

> **Un compito → una richiesta → controllo → commit.**

## Il progetto finale

Ogni studente realizza il proprio progetto con 3 requisiti visibili e testabili, scegliendo tra:

- **Web:** HTML, CSS e JavaScript, pubblicato con GitHub Pages (per esempio un quiz, un gioco o un portfolio).
- **Arduino:** C++ nel simulatore Wokwi, condiviso con un link (per esempio un semaforo o un contatore).

Nell'ultima lezione presenti il progetto e spieghi con parole tue una parte del codice.

## Strumenti

VS Code, Git, GitHub, GitHub Copilot Free, Cline e OpenRouter. Per il corso bastano i piani gratuiti.

## Regole di sicurezza

- Non scrivere mai chiavi API, password o dati personali nei prompt o nei file.
- Leggi ogni comando prima di approvarlo e non usare «Always Allow».
- Non accettare codice che non sai spiegare.
- Sui PC condivisi, a fine lezione esci da GitHub in VS Code e nel browser.
